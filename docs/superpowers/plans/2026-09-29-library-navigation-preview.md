**Goal:** 重排首页与曲库筛选，给“我的曲库”增加直接搜索和试听。

**Architecture:** 保持现有筛选值和音频搜索链路。用小型纯函数表示来源层级及视图状态；DOM 代码留在 `app.js`，试听使用独立音频元素。

**Tech Stack:** 原有 HTML/CSS/ES modules、Node test runner、浏览器 localStorage。
