# 一键启动器设计

## 目标

在项目根目录提供 `一键启动.bat`。用户双击一次即可启动本地网站服务器和 B 站代理，并在两个服务可用后打开浏览器访问 `http://127.0.0.1:8080/`。

## 行为

- 始终从 BAT 所在目录运行，目录名包含空格时也能工作。
- 检查 `127.0.0.1:8765`；未监听时用 Node.js 在独立的最小化窗口运行 `bili-proxy.mjs`。
- 检查 `127.0.0.1:8080`；未监听时用 Python 在独立的最小化窗口运行 `python -m http.server 8080 --bind 127.0.0.1`。
- 已监听的服务直接复用，使重复双击不会产生端口冲突。
- 最多等待 30 秒。两个端口均可连接后，使用系统默认浏览器打开网站。
- 缺少 Node.js、缺少 Python 或等待超时时，显示可操作的中文错误并保留窗口。

## 边界

启动器不修改网站、代理、数据库和音频来源逻辑。两个服务分别保留自己的控制台窗口，用户关闭对应窗口即可停止该服务。

## 验证

- 静态测试验证命令、端口、重复启动保护、超时处理和浏览器地址。
- 实际运行 BAT 后检查 8080、8765 均处于监听状态，并请求网站首页与代理健康检查。
