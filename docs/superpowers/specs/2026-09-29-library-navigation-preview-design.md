# 曲库导航与试听设计

## 目标

缩短从首页选曲库、浏览歌曲到开始单人挑战的路径，同时保留现有所有曲库来源的筛选语义。

## 选择方案

比较过六枚并排按钮、单一下拉框和分层选择。采用分层选择：第一层为“全部歌曲 / 官方曲库 / 我的导入”；选“官方曲库”后，第二层为“全部官方 / 原有曲库 / 季度新番”，选季度新番后出现已发布季度。现有 `null`、`builtin`、`legacy`、`custom`、`season:YYYY-MM` 值不变。

首页保留四种单人玩法和联机入口，将“我的曲库”与当前曲库摘要移到开局操作附近；设置、排行榜、联机作为次级入口。我的曲库增加覆盖旧歌、季度歌和导入歌的统一曲目搜索页；季度页直接提供搜歌、仅追番开关和试听按钮，不要求先进入设置。

试听用独立 `<audio>` 元素调用现有音频搜索。一次只播一首；切歌或离开曲库时停止。搜索、播放失败、仅找到视频来源时给出明确状态与外部试听链接。试听时记录本机成功或失败，但不影响正在答题的播放器和 PK 数据。

## 验证

测试来源值到两层 UI 的映射、季度选项、试听的并发取消和停止行为；浏览器验证首页路径、六种来源语义、搜索、试听状态、移动端布局。运行现有测试与曲库校验。
